# Step 3：接入 WebMCP 与 WebSkills 基础设施

发送如下指令给 Agent：

```text
/opentiny-ai-app-integration 为当前项目接入第三步 WebMCP 与 WebSkills 基础设施。
```

Agent 完成基础设施后，开发者再在业务页面注册工具，并在 `src/skills/<业务名>/SKILL.md` 中编写工具使用说明。完整步骤和 `doc-ai` 示例代码见 [Agent 操作手册](../agent-guide#step-3接入-webmcp-与-webskills-基础设施)。

Agent 不根据页面内容自行生成业务工具。
