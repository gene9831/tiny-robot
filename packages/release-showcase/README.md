# TinyRobot 1.0 宣传素材录制项目

一个私有的 Vue + Vite 项目，供 `1.0.0宣传文章.md` 截图和录制动图使用。网页录制固定使用 npm 发布的 TinyRobot Components、Chat、Kit 和 SVGs `1.0.0-rc.8`，对应标签提交 `18ce5d6b3fc1bebcffaa551e0d898ee12563baa2`。

## 启动

从仓库根目录复制到独立目录后安装，以免混用当前工作区里的本地组件或依赖：

```bash
showcase_source="$PWD/packages/release-showcase"
showcase_dir=$(mktemp -d)
rsync -a --exclude=node_modules --exclude=.recording --exclude=dist --exclude=test-results \
  --exclude='.env*' "$showcase_source/" "$showcase_dir/"
cd "$showcase_dir"
pnpm install
RELEASE_SHOWCASE_ENV_DIR="$showcase_source" pnpm dev
```

普通演示使用本地模拟服务。只有「真实模型与附件」场景需要百炼 API Key。使用会提示审批安装脚本的 pnpm 时，可运行 `pnpm approve-builds`，为 Vite 的 `esbuild` 启用所需脚本。

打开 [录制工作台](http://127.0.0.1:4175/)。端口固定为 `4175`，被占用时会报错，不会切换到其他地址。

## 真实模型与附件

在仓库的 `packages/release-showcase/.env.local` 填入百炼 Key，再用上面的命令启动或重启预览。这个文件由本地 Vite 服务读取。

```dotenv
DASHSCOPE_API_KEY=
DASHSCOPE_BASE_URL=
```

`DASHSCOPE_BASE_URL` 可留空，默认使用与 TrChat 的 Qwen Provider 一致的 `https://dashscope.aliyuncs.com/compatible-mode/v1`。如果 Key 对应专属工作空间或其他地域，填写控制台显示的 OpenAI 兼容 Base URL，保留 `/compatible-mode/v1` 路径。

打开[真实模型与附件](http://127.0.0.1:4175/?clean=1#live-chat)。切换到已有会话，拖入一张 2 MB 以内的 PNG 或 JPEG，在附件卡片出现后输入问题并发送。也可以粘贴图片，或用「添加图片」选择文件。发送后图片显示在用户消息里，百炼的 `qwen3-vl-plus` 流式回复。录制可以用[现有 TrChat 架构图](../../docs/release-assets/v1.0.0/tinyrobot-trchat-architecture.png)作样例，按下方分镜提问。

## 画面准备与重录

- 工作台预览建议使用 `1440 × 1000`。录制时使用浅色主题、100% 缩放。附件场景取景为 `1040 × 740`，导航和浮窗为 `1040 × 650`，工具栏为 `940 × 490`，模型选择为 `620 × 430`。
- 在顶部切换场景，点击「重置当前场景」恢复初始数据。工具确认场景会恢复当前标签页等待确认的会话，其他场景可通过刷新或离开场景重置。
- 点击“隐藏录制控制栏”，或按 **Alt + R**（Mac 为 Option + R）隐藏/显示场景导航和录制提示。清爽模式仍保留产品本身的交互按钮。
- 也可直接打开带 `clean=1` 的链接，例如 [扩展管理清爽模式](http://127.0.0.1:4175/?clean=1#extensions)。需要重置时先按 Alt + R 恢复控制栏。
- 以操作结果稳定后能看到多久来检查字幕。关键结果留约 2 秒，需要同时读字幕和结果时再多留片刻，最终结果可停约 3 秒。
- 录制应用区域或裁去浏览器标签与地址栏；正式素材中的终端画面也应裁去机器路径。无需把录制工作台的辅助提示带入文章。

## 建议的录制顺序

### 1. 会话、附件与流式回复（约 15 秒）

在「真实模型与附件」场景中，从「本周产品进展」开始录制，点击左侧「1.0 版本体验」。

1. 拖入 TrChat 架构图，让输入框内的附件卡片停留约两秒。
2. 输入「请看图，完整聊天应用和仅接入聊天界面分别用哪些组件？只列两条简短答案。」并发送。
3. 让用户消息中的图片和逐步出现的回复入镜。回复完成后停留两秒以上，同时保留图片和两种接入方式。

发布素材见[会话、附件与流式回复动图](../../docs/release-assets/v1.0.0/tinyrobot-chat-streaming.gif)。

### 2. Chat 其他能力分镜

#### 长对话导航（约 10 秒）

打开消息目录录制入口，从一段已经滚到底部的长对话开始，同时保留目录和消息区。悬停在右侧标记上可展开目录。

| 时间    | 用户操作                                 | 画面要点                             |
| ------- | ---------------------------------------- | ------------------------------------ |
| 0–2 秒  | 停在最新回复                             | 目录和当前对话同屏                   |
| 2–5 秒  | 点击目录中的「上线前需要准备哪些材料？」 | 对话跳到这条历史提问，目录高亮对应项 |
| 5–7 秒  | 滚到下一条提问                           | 目录高亮随滚动切换                   |
| 7–10 秒 | 点击回到底部                             | 回到最新回复                         |

#### 聊天布局（约 8 秒）

打开浮动聊天录制入口。开场时浮窗已打开，固定取景范围，画面保留窗口移动所需的空间。

| 时间   | 用户操作     | 画面要点                             |
| ------ | ------------ | ------------------------------------ |
| 0–2 秒 | 停在初始位置 | 可辨认浮窗中的消息和输入区           |
| 2–5 秒 | 拖动窗口顶部 | 浮窗整体移动，聊天内容随窗口移动     |
| 5–8 秒 | 拉伸窗口边缘 | 浮窗尺寸变化，聊天内容随尺寸重新布局 |

#### 输入工具栏（约 7 秒）

打开工具栏录制入口。初始配置把 MCP 排在模型选择前面。取景保留顺序开关、工具栏和模型面板。 [工具栏演示素材](../../docs/release-assets/v1.0.0/tinyrobot-chat-toolbar.gif)

| 时间   | 用户操作             | 画面要点               |
| ------ | -------------------- | ---------------------- |
| 0–2 秒 | 停在初始顺序         | 模型选择位于 MCP 之后  |
| 2–4 秒 | 开启「模型选择优先」 | 模型选择移到 MCP 前面  |
| 4–7 秒 | 点击首位的模型选择   | 模型面板从新的入口打开 |

### 3. 统一扩展面板

启动项目后，在独立录制目录的另一个终端运行：

```bash
pnpm record:extensions
```

脚本打开扩展页的清爽模式，按「效率工具」筛选 MCP，搜索并安装「日程助手」，再切到 Skills 标签导入 `samples/weekly-report` 文件夹。确认导入后回到「已安装」列表，最后展示应用通过 `tabs` 配置的「业务工具」标签页。MCP 安装和业务工具使用演示数据，Skill 由 Kit 解析。每次从相同的初始状态开始并配有步骤字幕。录制需要 Playwright Chromium 和 FFmpeg，GIF 输出到项目的 `.recording/mcp-and-skill.gif`。

也可以打开 [扩展页清爽模式](http://127.0.0.1:4175/?clean=1#extensions) 手动重录。导入时选择整个 `samples/weekly-report` 文件夹，其中包含 `SKILL.md` 和 `references/format.md`。刷新页面即可重置。

### 4. 工具确认（合辑约 21 秒）

录制场景由 [ApprovalScene.vue](src/scenes/ApprovalScene.vue) 实现。输入使用 `TrSender`，对话和审批操作由 `TrBubbleList` 展示。Kit 持久化暂停回合，录制页通过 `sessionStorage` 保存等待确认时的会话消息。「保存」使用本地模拟结果。审批界面、交互或文案更新后，用目标版本重录，再刷新 [工具确认合辑](../../docs/release-assets/v1.0.0/tinyrobot-tool-approval.gif)。

1. 从独立录制目录运行 `pnpm dev`，打开 [工具确认清爽模式](http://127.0.0.1:4175/?clean=1#approval)。审批素材沿用 `1100 × 630`、浅色主题和 100% 缩放。
2. 每段从新浏览器会话开始，或先显示控制栏并点击「重置当前场景」。快速逐字输入「请把这份周报保存到团队工作区。」并点击发送。让双方头像、请求气泡和「等待确认 · 保存周报」卡片入镜。
3. 在允许分支直接点击「允许」，保留「已调用」状态和最终回复约 2.5 秒。
4. 允许结果后接上拒绝分支的等待画面，字幕切到「同一请求，改选拒绝」。等待确认时执行真实的浏览器刷新，可用 Playwright 的 `page.reload()`。录下刷新前和恢复后的同一条请求、同一张卡片，分别配「刷新页面」和「刷新后继续确认」。刷新前后各停留约两秒，恢复后点击「拒绝」，保留结果约三秒。
5. 合辑只保留一次输入和发送，用 FFmpeg 合成循环 GIF。可运行 `pnpm test --grep 'tool confirmation'` 验证刷新恢复和拒绝路径。文章插图位置见 [1.0.0 宣传稿](../../1.0.0宣传文章.md#工具调用确认)。

### 5. 模型与输入分镜

模型选择使用[独立录制入口](http://127.0.0.1:4175/?clean=1#model)，模板使用[模型与输入页](http://127.0.0.1:4175/?clean=1#composer)。动态首行提示使用独立场景，各段素材放在文章对应小节。

#### 模型选择（约 15 秒）

| 时间    | 用户操作                       | 画面要点                           |
| ------- | ------------------------------ | ---------------------------------- |
| 0–3 秒  | 从「通用助手」打开模型面板     | 同时看见通用模型和推理模型分组     |
| 3–9 秒  | 搜索「推理」，选中「推理助手」 | 结果随搜索收窄，选中后面板保持打开 |
| 9–15 秒 | 选择「深度」，关闭面板         | 触发器显示「推理助手 · 深度」      |

#### 多行首行提示（约 18 秒）

打开[首行提示清爽模式](http://127.0.0.1:4175/?clean=1#input-prefix)，以 `900 × 380` 分两段录制，再按顺序合成[宣传稿动图](../../docs/release-assets/v1.0.0/tinyrobot-sender-input-prefix.gif)。

1. **动态替换首行提示。** 点击「起草客户回复」，输入一行「客户反馈包裹未收到。」后发送。再次输入这行，切换到「生成交接摘要」，让标签更新、草稿保留的画面停留约两秒半，再发送。两次提交都用动态下划线标记结果里的任务名称。
2. **多行输入时的首行提示。** 从已选中「起草客户回复」且输入框为空的状态开始。输入「客户反馈包裹未收到。」，按 Enter 换行，再输入「已确认今天安排补发。」。保持同一任务，停在两行正文上，展示标签留在首行、第二行从输入区左侧开始。

#### 输入模板（约 18 秒）

从空输入框开始，在录制前关闭首行提示。录制 `900 × 380` 的画面，取景只保留「插入任务模板」按钮、输入框和提交结果。录制样式将外层 `.composer-panel` 的背景和边框设为透明，并将下拉菜单最小宽度设为 `112px`。展开时确认菜单仍挂在面板内，且选项完整入镜。 [模板操作动图](../../docs/release-assets/v1.0.0/tinyrobot-sender-template.gif)

| 时间     | 用户操作                                                       | 画面要点                                                         |
| -------- | -------------------------------------------------------------- | ---------------------------------------------------------------- |
| 0–4 秒   | 点击「插入任务模板」，展开「本周进展」，再选择「会议记录」     | 菜单完整展开，选中后字段原位更新                                 |
| 4–7 秒   | 点击发送，停在第一个提交结果                                   | 用动态下划线标记提交文本里的「会议记录」                         |
| 7–15 秒  | 再插入同一模板。点击字段右侧，按 Backspace，再键入「客户访谈」 | 下拉字段整块消失，两侧文字保留，「客户访谈」作为普通文本填在原处 |
| 15–18 秒 | 点击发送，停在第二个提交结果                                   | 用动态下划线标记提交文本里的「客户访谈」                         |

## CLI 录制

把录制项目复制到 rc.8 checkout 的 `packages/release-showcase` 后，从该 checkout 的仓库根目录运行。CLI 需要先安装该 checkout 的依赖。

```bash
# 用默认 basic 模板创建 Chat 项目
pnpm --dir packages/release-showcase cli:create

# 在准备好的 Vue 宿主中预览 add chat 的变更
pnpm --dir packages/release-showcase cli:preview
```

这两个命令执行 `packages/cli/bin/cli.js`，不会下载或调用 npm 上的 CLI。创建结果放在本项目忽略的 `.recording/my-chat-N/`，每次使用新编号；预览宿主位于 `.recording/vue-host/`，重复预览不会覆盖已有文件。不会修改真实业务项目，也不自动安装生成项目的依赖。

命令显式传入 `--runtime-version 1.0.0-rc.8`，让生成项目也使用已验证的包版本。实际运行生成项目时，按模板说明安装依赖并配置模型服务。

## 验证

安装依赖并启动预览后，在独立录制目录运行：

```bash
pnpm build
pnpm test
```

测试使用 Chromium，覆盖聊天发送与重置、扩展安装及真实本地 Skill 导入、工具允许/拒绝、模型选择与清爽模式。首次在新机器运行浏览器测试前，如提示缺少浏览器，可运行 `pnpm exec playwright install chromium`。脚本录制和测试都使用 Chromium。
